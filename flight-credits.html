PROJECT NOTES

폰의 자세를 비행기의 자세로.

휴대폰의 방향 센서로 측정한 회전을 MQTT 메시지로 발행하고, 컴퓨터의 Three.js 장면에서 구독해 비행기 모델에 반영한다. QR에 담긴 연결 번호로 두 화면이 같은 토픽을 사용한다.

연결과 움직임

Week 07 예제의 phone-pose.html과 mqtt-pose-twin.html을 바탕으로 QR 연결, 기준 자세 설정, 비행기 장면과 상태 표시를 구성했다. 공개 MQTT 브로커에 암호화된 WebSocket으로 연결하며, PC 제어판도 같은 MQTT 경로를 사용한다.

기준 자세와 현재 자세의 상대 회전을 쿼터니언으로 계산하고, 네 성분(qx·qy·qz·qw)을 MQTT로 전송한다. 기체는 수신한 쿼터니언을 직접 목표 자세로 삼아 부드럽게 보간한다. 축별 각도 제한은 없으며, 오일러각은 계기 표시에만 사용한다. 왕복 지연은 컴퓨터 → 브로커 → 제어 화면 → 브로커 → 컴퓨터의 응답 시간을 측정한 값이다.
