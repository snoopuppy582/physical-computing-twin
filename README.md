# 실감피지컬컴퓨팅 2주차

대상: 7평 원룸과 여닫는 문.

## 가정과 범위

- 사용자 정보: 집 전체 약 7평.
- 7 × 3.3 = 23.1㎡를 4.2 × 5.5m 직사각형으로 단순화.
- 천장 높이 2.4m, 문 폭 0.9m·높이 2m·두께 0.04m는 실측 전 가정.
- 가구와 욕실·주방 위치는 개념화를 위한 배치안. 실제 집을 측량한 결과가 아님.
- 강의 제공 examples v2의 room-template.html, w02-spz-viewer.html을 바탕으로 작업.

## A. 트윈 대상 박스 개념화

`room-template.html`에서 공간과 움직일 문을 직육면체로 표시합니다.
범례: 연회색=벽, 파란색=움직일 문, 갈색=책상, 베이지=침대, 진회색=옷장, 연녹색=주방, 분홍색=욕실.

## B. AI 기반 모델링

Blender MCP로 A와 같은 방문을 모델링했습니다. `door-model.html`에서 확인하고 `assets/room-door.glb`를 내려받습니다. 편집 원본은 `assets/room-door.blend`입니다.

AI 사용내역 3줄:
1. Codex에서 Blender MCP를 연결해 박스 장면과 같은 방문을 만들었다. 문 치수 0.9×2×0.04m는 실측 전 가정값을 사용했다.
2. 기본 문판에 양면 손잡이와 경첩 3개, 작은 모서리 둥글림을 추가했다. 한국어 Blender의 재질 노드 이름 차이로 난 오류는 노드 유형으로 찾도록 수정했다.
3. 경첩 쪽 원점을 유지하고, 기본 큐브가 내보내기에 섞이지 않게 현재 장면만 GLB로 저장했다. 파일 크기는 109,504바이트로 20MB 이하다.

## C. 테스트 스캔

`w02-spz-viewer.html`에 Scaniverse에서 내보낸 실제 테스트 SPZ를 넣습니다.
현재 본인 테스트 SPZ는 아직 제공되지 않았습니다. 뷰어의 나비 샘플은 제출용 스캔을 대신하지 않습니다.

스캔 계획 초안(실제 촬영 일정과 공간 동의 확인 후 제출):
1. 무엇을: 집 입구의 방문과 주변 벽·바닥.
2. 언제·조명: 촬영 날짜 미정. 밝기가 일정한 시간에 실내등을 켜고 촬영.
3. 동의: 공간 사용자의 촬영 동의를 확인하고 사람이 없는 상태로 촬영.
